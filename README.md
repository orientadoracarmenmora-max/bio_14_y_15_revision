# Procesos geológicos · Temas 14 y 15

Aplicación estática para 1.º de Bachillerato. Abre `index.html` en el navegador. Mantén los archivos HTML, CSS y JavaScript de la aplicación en la misma carpeta.

## Subir a GitHub Pages

1. Descomprime el ZIP. En GitHub crea un repositorio nuevo, por ejemplo `bio_14_y_15_revision`.
2. Usa **Add file → Upload files** y sube todos los archivos descomprimidos directamente a la raíz de la rama `main`. Incluye `index.html`, `estilo.css`, todos los archivos `.js` (incluido `puntero.js`) y todas las imágenes `.webp`. Guarda con **Commit changes**.
3. En el nuevo repositorio, abre **Settings → Pages**. En **Source** elige **Deploy from a branch**, selecciona `main` y `/(root)`, y pulsa **Save**.
4. Abre el enlace que aparezca en **Settings → Pages** cuando termine la publicación. Su formato habitual es `https://TU-USUARIO.github.io/bio_14_y_15_revision/`.

La web se puede abrir en local. La lectura en voz alta usa la voz de Google en español de España por defecto. Si solo está disponible otra voz de Google en español, utiliza esa voz. Si el navegador no ofrece ninguna, la aplicación muestra un aviso. El progreso se guarda en el navegador cuando permite el almacenamiento local. En GitHub Pages, el enlace de publicación puede ser público. El paquete contiene la aplicación y sus apuntes originales. [Configuración oficial de GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
